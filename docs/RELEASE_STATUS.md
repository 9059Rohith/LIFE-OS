# LIFEOS release status — 18 September 2026

## Verdict

LIFEOS runs locally in live mode. A separate password-protected **live Railway service** runs at `https://lifeos-live-production.up.railway.app`. It passed public login, work-record write/read-back, service restart persistence, and browser UI checks. The existing owner's Google grant was transferred through an encrypted one-use SSH import after a hosted volume backup. Gmail, Calendar, Drive, Discord and WhatsApp passed hosted live read checks while the Windows desktop app was connected. It is **not yet a completed live cross-provider product**: the registered OAuth client still rejects new hosted callback requests, and a verified Calendar → Discord → WhatsApp send has not passed. The older `lifeos-public` service remains a protected demo. The Windows installer is an online companion, not a bundled backend release.

## Verified on the current source

- Google consent is stored for the local and hosted owner. Gmail, Calendar, Drive and Discord pass current hosted read checks. The dedicated local Playwright WhatsApp worker remains an optional alternative whose latest check returned `needs_attention`.
- The Electron window hosts the actual Discord and WhatsApp websites in separate, sandboxed `WebContentsView` sessions. Google OAuth opens in the system browser; the callback is bound to a one-use owner state. The packaged executable loaded both provider sites and preserved its sessions after restart. Its signed-in WhatsApp view is now the source of owner-approved bridge jobs; the hosted WhatsApp panel returned one real conversation item and the live check reported `read_access_verified` while that desktop was connected. No WhatsApp send was made in this acceptance run.
- The live **My work** screen starts empty and persists projects, goals, tasks, habits, notes, dated habit check-ins, linked progress, a 14-day local agenda, work-history activity and due reminders. Google Calendar events appear in that agenda when the live Google API is available. None of these live records are seeded or simulated. The dashboard fetches one owner-scoped snapshot per navigation to stay below the request limit. Link options include all saved projects, goals and tasks; a regression covers an older project after more than 100 records.
- Data export includes work records, activity and reminder acknowledgements without exporting OAuth tokens. Owner deletion removes them with the rest of the workspace. A schema revision adds an owner/kind/time index for history queries. New audit entries query only the latest chain record, and a 102-project regression verifies the chain.

## Release blockers

1. **Hosted Google reconnect:** add `https://lifeos-live-production.up.railway.app/api/integrations/google/callback` to the OAuth web client's authorized redirect URIs so the owner can reauthorize if the transferred grant expires or is revoked. The current grant passes live Gmail, Calendar and Drive reads.
2. **Live cross-app acceptance:** the same-view WhatsApp bridge is deployed and real chat reads pass, but no single approved event has yet updated Calendar and sent both Discord and WhatsApp notifications with independent read-back on the current revision. Read-access checks cannot substitute for delivery proof.
3. **Desktop distribution:** the unsigned Windows companion installer targets the hosted HTTPS workspace by default, with an explicit local development override. Hosted sign-in, both provider views and restart persistence passed packaged checks. Publisher signing and installer reputation have not been established.
4. **Production scale and recovery:** the supported deployment is one owner and one backend process. Dedicated account registration, owner-specific Discord/WhatsApp configuration, horizontal workers and load acceptance are not complete. The live Railway volume has no recorded backup or backup schedule; both backup creation and schedule mutation returned `Not Authorized` through the authenticated Railway API on 18 September. Do not claim thousands-of-users readiness or a hosted recovery point.
