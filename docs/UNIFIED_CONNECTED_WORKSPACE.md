# Unified connected workspace

Replace the live Connected apps tab switcher with one continuous page, opened by default after live sign-in. Discord is the main surface: dark server rail, configured channel list, channel heading, real message stream, and a read-only send bar. Gmail is a white inbox with real message detail beside it. WhatsApp, Calendar, Drive, and Maps remain visible below, each with its own familiar interaction pattern. Show cached integration statuses and the latest real LIFEOS event's affected applications in the same top strip.

Each provider panel fetches independently so a slow WhatsApp browser does not hold back the other screens. Discord author avatars come from Discord's CDN when the API provides a valid user ID and avatar hash. The top strip shows cached connection statuses and supports an in-place connection recheck. A lower ripple panel displays real actions from the latest LIFEOS event. Only data and channels returned by authorized APIs are shown. No fake servers, folders, map tiles, chats, events, send controls, or Compose actions. Existing LIFEOS planning and approval remains the path for mutations. The visual concept in `.private/unified-app-concept.png` establishes the density and arrangement; its placeholder content and simulated map are not implementation data.

On wide screens Discord and Gmail sit side by side; the other provider views form a second row. At tablet widths the columns collapse while preserving the one-page flow. On phones every provider appears in a vertical sequence with no horizontal overflow. Verify all panels render, Gmail detail opens, data matches the configured providers, one panel failure remains local, and refresh updates without page switching.
